# MusCos（仮）— 耳とリズムのトレーニングアプリ

ブラウザで遊べる、音感とリズム感を鍛えるための小さな練習アプリです。
鳴った音をピアノの鍵盤で当てる「音あて」と、画面に表示されたリズムに合わせて叩く「リズム」の2つを収録しています。

> **開発状況：第1版（試作）です。** 両方の遊びが一通り動きますが、スマホ実機での音とタイミングの調整はこれからです。

---

## 目的

- 音の高さを聴き分ける力（音感）を、ゲーム感覚で練習できるようにする
- 付点や3連符などのリズムを、目で見て・叩いて身につけられるようにする
- インストール不要で、PC でもスマホでもブラウザを開くだけで使えるようにする

## 主な機能

### 音あて（音階当てクイズ）
「開始」を押すと音が鳴り、画面のピアノ鍵盤で答えると正解・不正解が表示されます。

| モード | 出題される音 | 当てるもの |
|---|---|---|
| 簡単 | ド〜シ（C4〜B4）の白鍵 7音 | 音名 |
| 難関 | C3〜B6 の白鍵 28音 | 音名とオクターブ |
| 発展 | C4〜B4 の白鍵と黒鍵 12音 | 音名（♯/♭を含む） |
| 連続 | 上のいずれかの範囲から 2〜5音 | 鳴った順番どおりの並び |

- 音名は「ドレミ」「CDE」の切り替えができます
- 難関モードはスマホでは「音名 → オクターブ」の2段階で答えます
- モードごとの正解数と連続正解数をブラウザに保存します

### リズム
1小節を4拍（4つのブロック）に分けて1行とし、4小節分（4行）のリズムを表示します。今叩くべき拍が光り、拍の中を線が進んでいくので、それに合わせてタップやスペースキーで叩きます。

- テンポ（BPM）は 60〜180 で変更可能
- 難しさは初級・中級・上級・例題（付点と3連符）から選択
- 叩くたびに「ぴったり／おしい／ミス」を判定し、結果画面でズレの平均と「早め／遅め」の傾向を表示
- イヤホンなどで音が遅れて聞こえる場合に備えた「ズレの補正」機能つき

詳しい仕様は [docs/spec.md](docs/spec.md) を参照してください。

## 技術構成

| 項目 | 内容 |
|---|---|
| 構成 | HTML / CSS / JavaScript の静的サイト（現在はテスト開発のためサーバなし。将来の機能ではサーバを使う可能性あり） |
| 音 | Web Audio API、Tone.js（ピアノ音源の再生） |
| ピアノ音源 | Salamander Grand Piano のサンプル（インターネット経由で読み込み） |
| データ保存 | ブラウザの `localStorage`（設定・成績） |
| 対応端末 | PC（キーボード・マウス）とスマホ（タッチ） |

## 使い方

ビルドやインストールは不要です。JavaScript のモジュールを使っているため、ファイルを直接開くのではなく、ローカルのWebサーバ経由で開きます。

```bash
# プロジェクトのフォルダで（Python がある場合）
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。ピアノ音源とフォントをインターネットから読み込むため、ネット接続が必要です。

## デザイン

量産的な「AIっぽい」見た目を避け、人の手で作ったような画面を目指しています。候補3案（[docs/design-candidates.pdf](docs/design-candidates.pdf)）から、案B「レコード喫茶」（深緑・クリーム・真鍮色、太いゴシックの見出し）を採用しました。
